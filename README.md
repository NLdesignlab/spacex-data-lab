# SpaceX Data Lab

This project analyzes and visualizes SpaceX launch data to identify trends and factors influencing successful launches.

## Tools Used
- Python
- Pandas
- Matplotlib / Seaborn
- Jupyter Notebook

## Key Features
- Data cleaning and preprocessing of launch data
- Exploratory data analysis (EDA)
- Visualizations of success rate by launch site and booster version
- Payload mass vs. success analysis

## Goal
To explore patterns in the SpaceX launch history and build a foundation for future predictive modeling.
